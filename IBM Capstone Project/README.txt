GamblingCommentClassifier-and-IBM-Granite-Summarization-V2
This is the Modified version which is more clean than V1. A simple project to classify online gambling comments using a Bag of Words (BOW) approach, and using IBM Granite 3.3 8B Instruct to summarize the findings.

Overview
This project uses a Bag of Words representation with a Multinomial Naive Bayes classifier for binary classification, and IBM Granite 3.3 8B Instruct to summarize insights from the classified comments.

Features
Bag of Words feature extraction with CountVectorizer
Binary classification using Multinomial Naive Bayes
Summarization of classified comments using IBM Granite 3.3 8B Instruct
